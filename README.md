# comics-generator
Сервис для создания персонализированных диалоговых видеокомиксов по фотографиям персонажей и краткому текстовому описанию.

ИИ создаёт диалоги, стилизованные изображения и структуру ролика. Готовое видео собирается на устройстве из статических материалов и программных визуальных эффектов без диффузионной генерации видеоряда.
